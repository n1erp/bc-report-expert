# Report Expert 2.0 "Baboon" — release notes

**rex-2.0-baboon** · Released 7 November 2026 · Previous release: 1.0 "Marmoset" · Full list:
[CHANGELOG.md](CHANGELOG.md)

Baboon makes REX a complete RDLC designer for Microsoft Dynamics 365 Business Central. You can open a BC
layout, change its tables and groups, format it, preview it with real or sample data and save it back to
the AL project, without Microsoft Report Builder.

## Highlights

| Area | What you get |
| --- | --- |
| **Visual designer** | Rulers in cm or inches, bands, snapping and snaplines, multi-select, format toolbar, Properties pane that shows only what applies, expression editor, page setup with live preview. What you format is what you see on the design surface. |
| **Tables and groups** | Row and column groups (parent, child, adjacent), headers, footers and totals, insert/delete rows and columns inside or outside a group, merge/split, full group properties (sorting, filters, visibility, drilldown, page breaks, variables). |
| **Business Central layouts** | Nested list layouts are drawn in their real places; datasets, data source and the `<Code>` block are kept exactly as BC wrote them; data from BC XML, JSON or CSV, or typed sample data. |
| **Revisions** | Every change is a revision: undo/redo, history and audit log, stored in one local SQLite database. |
| **Preview and export** | PDF preview with parameters, one Export menu for PDF, Excel and Word, a configurable number of sample rows, a neutral sample picture. |
| **Rex** | Eight AI providers with current models, a key test that picks a working model, a provider-then-model picker with search. |
| **Agents** | The `rdlc-mcp` server now has 48 tools, including the designer's own operations and tablix structure tools. |
| **When something goes wrong** | An error dialog with the details a developer needs, the failing expression and its fields, Copy details and Report a bug. |

## Upgrading from 1.0

- **Install over 1.0.** Settings, recent files and recent projects are imported from the 1.0 JSON files on
  first start; the old files are left in place and can be deleted later.
- **API keys are now encrypted** for your Windows user. Your 1.0 keys keep working and are encrypted the first
  time Baboon loads them. A `copilot.json` copied to another machine or user will show "No API key";
  enter the key again there.
- **Re-test your AI providers** in Settings › Copilot AI providers › Test. Some models used by 1.0 are retired
  (for example `gemini-2.5-flash` for new Google accounts); Test switches to one that works.
- **Sample rows** now follow Settings › Preview › Sample data in every preview (1.0's designer preview always
  used 25 rows).
- **Default export folder** is gone from Settings; save dialogs remember the folder you last exported to.

## System requirements

- Windows 10 (19041) or Windows 11, x64.
- Microsoft Edge WebView2 Runtime for the embedded PDF viewer (REX still renders and exports without it).
- Optional: an API key for one of the AI providers, or Ollama running locally.
- To build from source: .NET 10 SDK.

## Known issues

- Colours set by an expression, and black text, are drawn in the theme's text colour on the design surface so
  the layout stays readable on dark themes; very dark colours can be hard to read there. The PDF is exact.
- The report center's Data and Parameters tabs are hidden in this release.
- Report a problem from the error dialog (**Report a bug**) or at
  [github.com/n1erp/bc-report-expert/issues](https://github.com/n1erp/bc-report-expert/issues/).

## Deployment checklist

1. `dotnet test` on Windows (all test projects, including the WPF ones and PDF rendering).
2. `.\scripts\build-release.ps1` — check that the artifacts are named `v2.0-Baboon`.
3. Install the installer on a clean Windows user; open a BC layout, preview it, export PDF/Excel/Word.
4. Upgrade test: install over 1.0 with an existing `copilot.json`; check that keys still work and are stored
   as `dpapi:` values.
5. Submit the MSIX to the [Microsoft Store](https://apps.microsoft.com/detail/9nwqjz08pqzd).
6. Publish the MCP package (`ReportExpert.Rdl.Mcp` 2.0.0) and update the MCP registry entry
   (`io.github.n1erp/rdlc-mcp`).
