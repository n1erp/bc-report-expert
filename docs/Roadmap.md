# Roadmap

Current release: **rex-2.0-baboon**. These items are not in it.

- Route the workspace preview window through the same report engine as the designer
- Optional Strict safety policy when opening a layout from an unknown source
- Put Localization in the shell, or remove the project
- Remove or connect the projects the app does not reference (`Application`, `Infrastructure`, `Plugins`, `Shared`, and the parallel `Reporting.*` libraries)
- One dependency-injection container for the shell

Propose a change with a feature request on [GitHub](https://github.com/n1erp/bc-report-expert/issues).
